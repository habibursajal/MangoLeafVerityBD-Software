## 🧬 Technical Architecture
Unlike standard single-model classifiers, this software employs a **Multi-Model Ensemble Strategy** to ensure robust feature extraction and minimize inference bias.

### 1. Hybrid Ensemble Core (Ensemble x4)
The engine integrates four state-of-the-art architectures to achieve a balanced synergy between local and global feature learning:
* **Vision Transformers (ViT):** `DeiT-Tiny` and `Swin-Tiny` for capturing global context and intricate leaf textures.
* **Convolutional Neural Networks (CNNs):** `EfficientNetB0` and `MobileNetV2` for hierarchical spatial feature extraction and efficiency.
* **Weighted Softmax Fusion:** Final predictions are calculated through a weighted sum of probabilities from all four models, maximizing diagnostic precision.

### 2. Validation Gatekeeper (OOD Detection)
To prevent **Out-of-Distribution (OOD)** errors, the system includes a strict **Confidence Thresholding (65%)** mechanism. If the input image (e.g., human faces, non-agricultural objects) does not match the learned patterns of the `MengoLeafVerityBd` dataset, the system intelligently rejects the input to maintain data integrity.

## 📊 Dataset & Performance
* **Dataset Name:** `MengoLeafVerityBd`
* **Target Classes:** 8 Varieties (e.g., Amropali, Himsagor, Harivanga, Surjapuri, etc.)
* **Preprocessing:** Stochastic Image Augmentation, 224x224 Resolution, ImageNet Normalization.
* **Optimization:** Stochastic Gradient Descent (SGD) with Momentum and OneCycleLR Scheduler.
